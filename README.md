# 课屿 · Teachshelf for macOS

原生 macOS 课程资料管理器。用课程组织文件，在资料、待办、日历和作业文件夹之间切换；文件留在本机，无需账户或云服务。

本目录中的 macOS 应用使用 **SwiftUI、AppKit 和 Swift**。`example/` 保留原 Windows WPF 项目，作为业务行为与交互的参考实现。macOS 版使用独立的元数据格式，目前不能直接读取 Windows 版资料库；原始课程文件可重新导入。

## 本机启动

需要 **macOS 14 或更高版本**，以及包含 Swift 6 或更高版本的 Xcode Command Line Tools。开发工具尚未安装时，可运行 `xcode-select --install`。

在本项目目录运行：

```sh
./scripts/run-macos.sh
```

首次启动会编译 Release 版本并生成 `build/Teachshelf.app`；也可以在 Finder 中双击 `Start.command`。生成后可直接双击 `.app`，或把它复制到「应用程序」文件夹。

修改源码后重新构建：

```sh
./scripts/build-macos.sh
./scripts/run-macos.sh
```

构建脚本使用本机架构，并对应用进行 ad hoc 签名，适合在本机运行。发布给其他用户前，需要另行配置 Developer ID 签名和公证。

## 使用方式

- **课程**：按课程管理资料与任务，设置颜色，归档已结束的课程。
- **资料**：导入文件，编辑标题、类型、标签和备注，通过搜索与课程筛选定位内容。在列表或封面视图中浏览，使用 macOS 默认应用打开原文件。
- **待办**：记录截止时间、完成状态和关联课程，可与资料关联。
- **日历**：按日期查看任务安排与截止时间。
- **作业文件夹**：每门课程都有普通磁盘目录，可在 Finder 中打开，存放题目、草稿、代码和成果。
- **外观**：设置浅色、深色或跟随系统。在「调整强调色」中选择 12 种预设、使用 macOS 取色器或输入 HEX；选择后即时预览，保存才写入资料库，取消恢复原色。支持恢复默认松柏绿，课程颜色及可选课程边框保持独立。界面自动适配高对比度和不同明暗背景。

导入时可选择 **复制入库** 或 **引用原文件**。复制入库会把文件副本保存在资料库内；引用模式只记录原路径，因此原文件移动或删除后需要重新定位。作业文件夹中的文件不会自动成为资料记录。

## 数据与备份

默认资料库存放于：

```text
~/Library/Application Support/Teachshelf
```

资料库保存课程、资料和待办的 JSON 元数据，以及入库的文件副本与课程作业目录。可通过应用中的资料库管理操作备份和恢复。

备份是以 `.teachshelfbackup` 结尾的 macOS 文件包，包含资料库元数据、入库副本和作业文件夹。**外部引用的文件不会复制进备份**，恢复后仍需要原文件位于对应路径。对备份使用 Finder 的「显示包内容」可查看其中的普通文件。

恢复备份前，当前资料库的元数据与文件会保留到资料库内的 `History/Restore-…` 目录。迁移资料库时请选择一个空文件夹；复制完成后应用切换到目标资料库，并保留原目录。备份与迁移都会保留仍在资料库磁盘目录中的文件，包括已移除资料记录后留下的副本。

## 开发与验证

```sh
swift build
./scripts/test-macos.sh
./scripts/build-macos.sh
```

构建和测试脚本将缓存写入项目内的 `.build/`。测试脚本运行 Swift Testing，并补充 Command Line Tools 所需的测试框架与插件路径。

`Sources/TeachshelfCore/` 负责数据模型、资料库读写和文件管理；`Sources/Teachshelf/` 负责原生界面与系统集成；`Tests/TeachshelfCoreTests/` 验证核心业务行为。界面验证需在 macOS 上实际启动应用。

本机已通过 45 项测试，覆盖原子保存失败回滚、独占锁、资料复制与引用、重新定位、自定义类别、作业目录与挂载、任务归档与撤销、配色预览及取消、对比度、旧索引兼容、备份恢复与迁移。实际原生界面已检查课程创建、三文件批量导入、标签与备注保存、文件封面、Quick Look、关联待办与日历同步、作业子目录创建和文件复制，以及强调色预览取消、保存后重启读取、浅深色显示和课程边框开关。验证数据独立保存在 `build/QA/`，不写入默认资料库。

另有原生布局回归测试，检查 1020×680 与 1260×800 两种窗口内容尺寸下，切换资料、日历、待办、作业和设置不会改变窗口尺寸或最小尺寸约束，并验证分栏内容不会越过窗口右边界。v1.0.1 统一了页面标题、按钮和课程下拉菜单样式，并让待办筛选栏在窄窗口中自适应排列。
