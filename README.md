# 课屿 · Teachshelf for macOS

原生 macOS 课程资料管理器。用课程组织文件，在资料、计划和作业文件夹之间切换；文件留在本机，无需 Teachshelf 账户。

本目录中的 macOS 应用使用 **SwiftUI、AppKit 和 Swift**。`example/` 保留原 Windows WPF 项目，作为业务行为与交互的参考实现。macOS 版使用独立的元数据格式，目前不能直接读取 Windows 版资料库；原始课程文件可重新导入。

## 本机启动

需要 **macOS 14 或更高版本**，以及包含 Swift 6 或更高版本的 Xcode Command Line Tools。开发工具尚未安装时，可运行 `xcode-select --install`。

在本项目目录运行：

```sh
./scripts/run-macos.sh
```

首次启动会编译 Release 版本并生成 `build/Teachshelf.app`；也可以在 Finder 中双击 `Start.command`。生成后可直接双击 `.app`，或把它复制到「应用程序」文件夹。

修改源码后重新构建：

```sh
./scripts/build-macos.sh
./scripts/run-macos.sh
```

构建脚本使用本机架构，并对应用进行 ad hoc 签名，适合在本机运行。发布给其他用户前，需要另行配置 Developer ID 签名和公证。

## 使用方式

- **课程**：按课程管理资料与任务，设置颜色，归档已结束的课程。
- **资料**：导入文件，编辑标题、类型、标签和备注，通过搜索与课程筛选定位内容。在列表或封面视图中浏览，使用 macOS 默认应用打开原文件。
- **计划**：统一课程、考试、自主规划、志愿活动、作业和主动划出的“空”。月视图默认显示 DDL，其他安排可在详情中手动加入；周视图默认打开，整周与全部11节课程同屏，左侧时间和节次分列显示，节次仅显示数字；选中日使用更深的中性灰底色，不显示强调色或描边，与今天的强调色高亮独立；课程使用直角实心色块，遮住内部网格；活动按真实时间放置，时间刻度与卡片起止边界对齐，小课间折叠为共用边界，原先占用的高度分配给午休；课程和普通计划横向贴齐日期列，普通计划的强调色边框衔接左侧圆角，今天的星期格独立于所选日期持续高亮；午休和夜间保留分隔，夜间标签居中，底部边界线完整收口；日期右侧用青点提示全天计划、红点提示 DDL，点击跳转到当天日视图对应分区，全天与截止详情置于时间安排之前；移除原全天／截止行，腾出的高度平均分给早间和晚间。筛选、操作与当天详情集中在右侧。
- **计划编辑**：手动创建的是活动计划，有具体执行时段时可在周视图单击选中、双击编辑；拖动卡片整体移动，拖动上下边缘分别调整开始或结束，自动吸附最近10分钟。右侧开始／结束的±按钮精调1分钟；选中卡片后，上下方向键整体移动10分钟，左右方向键移动到前后一天，键盘±整体精调1分钟。时长至少1分钟，时间调整保持在当天00:00至24:00内；已有跨天计划从详情编辑。固定计划关闭编辑时不可选中，双击可查看详情；开启“编辑固定计划”后才能选中和调整，关闭开关会取消固定计划的选中状态；分钟级修改只影响本次课并支持撤销。全天计划和固定 DDL 从日期旁的圆点进入日视图查看与编辑。空白处拖出时段可创建默认名为“空”的普通计划，也可从新建菜单创建并改名。“空”无特殊保护。执行起止、截止时间、重复规则、地点、课程与资料关联可分别填写；计划可独立选择预设颜色、系统取色或HEX，关闭自定义后跟随课程／强调色；系统调色板在点击其他区域、离开编辑器或切换应用时自动收起；重复计划可仅为本次设色，课程信息中的颜色设置作用于同一上课时段的所有周次；截止会自动投影为固定 DDL 子计划，移动执行不改变截止，移动 DDL 同步主计划截止。
- **快捷入口**：侧栏六个图标分别打开全部资料、收藏、最近打开、未分类、作业文件夹和待完成计划。作业文件夹保留本次会话选择的课程或公共目录；待完成入口直接打开统一计划列表，默认显示所有日期与未排期的未完成事项，从这里新建时默认需要确认完成。
- **计划管理**：支持每日、每周、每月重复及结束日期；修改、取消或移除重复安排时可选择仅本次、本次及以后或整组。需要确认完成的计划可勾选完成，其他普通安排无需打卡。计划列表提供待安排、待完成、已完成、取消和归档筛选，保留临时变更与恢复入口。修改和删除可撤销，取消或删除主计划同时更新对应 DDL。
- **作业文件夹**：每门课程都有普通磁盘目录，可在 Finder 中打开，存放题目、草稿、代码和成果。
- **外观**：点击设置中的日夜开关切换浅色／深色，太阳与月亮滑动交替，云层与星光随之变化；勾选「跟随系统」可自动同步 macOS 外观，右键开关也可选择三种模式。选择随资料库保存，开启「减少动态效果」时立即切换。在「调整强调色」中选择 12 种预设、使用 macOS 取色器或输入 HEX；选择后即时预览，保存才写入资料库，取消恢复原色。支持恢复默认松柏绿，课程颜色及可选课程边框保持独立。界面自动适配高对比度和不同明暗背景。

侧栏的全部资料、收藏、最近打开、未分类、作业文件夹和待完成计划以六个图标横排，悬浮显示名称；待完成图标进入统一计划筛选。课程卡片沿用原项目的像素潮汐：悬浮推进、选中铺满、切换时撤回。资料列表保留原生多选、键盘和文件拖拽，并增加柔和的行高亮过渡；封面悬浮时轻微抬起，详情面板从右侧滑入。系统开启「减少动态效果」时使用静态反馈，窗口失活或离开视图后停止动态绘制。

导入时可选择 **复制入库** 或 **引用原文件**。复制入库会把文件副本保存在资料库内；引用模式只记录原路径，因此原文件移动或删除后需要重新定位。作业文件夹中的文件不会自动成为资料记录。

## 本科课表

在侧栏打开「计划」→「导入课表」。可选择南京大学官方网页登录，在本科教务中选择学期、切换到课表列表后读取；也可读取符合相同格式的本地 JSON。核对预览中的学期、课程、周次和解析提示后，再确认导入。当前只支持本科，不包含研究生系统。

网页登录使用独立的临时 WebKit 会话，关闭导入窗口后不保留该会话。应用不读取登录账号、密码或 Cookie；解析脚本随应用打包，仅在指定的南京大学本科课表页面运行。学校页面如有改版，解析器可能需要调整。登录可能需要校园网络或 VPN。

导入后，在「学期与作息设置」中填写 **第 1 周的周一日期** 和每节课的起止时间。未设置开学日期时，周课表仍按周次、节次显示；设置后，固定时段的课程会出现在周、日视图中，月视图需手动加入。未填写作息时只显示节次，不推测钟点。学期日期和周次按北京时间计算；切换视图或学期会保留所选日期，学期外可继续安排活动计划。月、日视图支持「全部学期」，课程筛选会同时作用于课程安排和待办；未分配课程的个人待办保留在学期汇总中。

学期设置支持根据已知日期和教学周次推算第 1 周周一，并提供可选的 11 节本科作息（按用户提供的课表截图整理，逐节可改）。例如 2026 年 10 月 14 日属于第 8 周时，推算起点为 2026 年 8 月 24 日。预设需手动选择，不会自动覆盖其他学期的设置；周课表按 11 节显示，若已导入课程或作息超过 11 节则自动扩展。

在周视图中开启「编辑固定计划」，可直接拖动课程卡片到目标星期与节次；卡片跟随指针抬起，目标格吸附高亮，松手后平滑移动。拖曳默认只调整当前这一次课，按 Esc 或在无效区域松手会回到原位。跨周移动、修改教室或节数可从课程详情的「调整安排」完成；选择「每周时段」可编辑固定星期、节次和上课周次，或移除整个时段。移除课表时段保留课程资料与其他计划。计划页提供上一项课表修改的撤销；临时调课也可在学期设置中恢复原安排。系统开启「减少动态效果」时使用静态反馈。

学期设置可以同时填写总周数与最后上课日期（含当天）。例如 18 周、2026 年 12 月 25 日结束时，第 18 周周末不会再投影课程，也不能拖动课程到结束日期之后。

日期明确的课程详情中可标记「本次停课」，只排除该日期的该次课程，其他周次照常显示。月、周、日共用停课记录；可在「学期与作息」中恢复并保存。重新导入时尽量按同一课程及固定时段保留停课关联，无法匹配的记录仍保存在设置中供核对。

同一学期重新导入会更新固定时段，保留课程身份、课程资料、关联计划、学期设置和临时调整记录。移除课表保留课程与资料；删除课程则保留课表中的名称、时段和教室快照。课表跟随资料库一起备份、恢复与迁移。

用于离线体验的人工示例位于 `Resources/Timetable/Sample-undergraduate.json`，仅供验证界面，不是真实上课安排。解析器来源、修改说明及 Apache-2.0 授权保存在 `Resources/Timetable/`。

## 数据与备份

默认资料库存放于：

```text
~/Library/Application Support/Teachshelf
```

资料库保存课程、资料和计划的 JSON 元数据，以及入库的文件副本与课程作业目录。可通过应用中的资料库管理操作备份和恢复。

当前使用元数据格式 5，兼容读取旧版格式 1、2、3、4；首次成功修改时保存为格式 5。旧版应用会拒绝打开新版格式，避免误写导致课表、临时调课或单次停课记录丢失。

备份是以 `.teachshelfbackup` 结尾的 macOS 文件包，包含资料库元数据、入库副本和作业文件夹。**外部引用的文件不会复制进备份**，恢复后仍需要原文件位于对应路径。对备份使用 Finder 的「显示包内容」可查看其中的普通文件。

恢复备份前，当前资料库的元数据与文件会保留到资料库内的 `History/Restore-…` 目录。迁移资料库时请选择一个空文件夹；复制完成后应用切换到目标资料库，并保留原目录。备份与迁移都会保留仍在资料库磁盘目录中的文件，包括已移除资料记录后留下的副本。

## 开发与验证

```sh
swift build
./scripts/test-macos.sh
./scripts/build-macos.sh
```

构建和测试脚本将缓存写入项目内的 `.build/`。测试脚本运行 Swift Testing，并补充 Command Line Tools 所需的测试框架与插件路径。

`Sources/TeachshelfCore/` 负责数据模型、资料库读写和文件管理；`Sources/Teachshelf/` 负责原生界面与系统集成；`Tests/TeachshelfCoreTests/` 验证核心业务行为。界面验证需在 macOS 上实际启动应用。

本机已通过 166 项 Swift 测试，覆盖原子保存失败回滚、独占锁、资料复制与引用、重新定位、自定义类别、作业目录与挂载、任务归档与撤销、配色预览及取消、对比度、旧索引兼容、备份恢复与迁移、原生列表多选，以及课表导入、重复导入、日期投影、冲突排列、官方页面边界、离线预览取消、课程跳转和元数据版本迁移。计划测试覆盖视图日期联动、学期外显示、虚拟周次隔离、上海时区边界、统一筛选、单次调课/停课与恢复、拖曳吸附和结束日边界、跨周同名课次冲突排列、撤销冲突保护、重导保留调整、旧版迁移和重新导入后的选择保留。新增计划测试覆盖执行与自动DDL独立、固定来源、月历手动加入、重复单次及未来变更、取消恢复、提前完成与重新打开、月末与多日投影、有效关联筛选和撤销冲突保护。另有 15 项本科解析器离线测试，覆盖多时段、单双周、中文分隔、单节课、自由时间、异常记录、固定列、嵌套表格、隐藏和重复表格及多表选择；安装 Node.js 时测试脚本会一并运行，也可单独运行 `node scripts/test-nju-parser.js`。

实际原生界面已检查课程创建、三文件批量导入、标签与备注保存、文件封面、Quick Look、关联待办与日历同步、作业子目录创建和文件复制，以及强调色预览取消、保存后重启读取、浅深色显示和课程边框开关。离线验证数据保存在 `build/QA/`。本科教务的实际登录会话已验证课表读取与预览，能够处理页面的固定列和嵌套表格；确认导入由用户核对后执行。

另有原生布局回归测试，检查 1020×680 与 1260×800 两种窗口内容尺寸下，切换资料、日程三种视图、待办、作业和设置不会改变窗口尺寸或最小尺寸约束，并验证分栏内容不会越过窗口右边界；另检查周课表在两种尺寸下完整容纳 7 天和全部 11 节，末节与周日仍可作为拖曳目标。v1.0.1 统一了页面标题、按钮和课程下拉菜单样式，并让待办筛选栏在窄窗口中自适应排列。

统一计划的演示界面已检查：月历默认DDL与手动加入、单日导航、DDL修改及撤销、普通“空”的改名与保存、固定编辑开关默认关闭。界面自动化的拖曳调用返回 `noWindowsAvailable`，因此实拖动画尚未通过自动化验证；时间映射、吸附计算和持久化移动由测试覆盖。
