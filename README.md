# 课屿 · Teachshelf for macOS

原生 macOS 课程资料与计划管理器。课程文件留在本机，可通过 Finder 管理，也可用内置 AI 助手或外部 MCP 客户端操作计划和资料信息。

当前应用版本 **1.16.1（77）**，资料库格式 **9**，备份包格式 **1**。主线使用 **SwiftUI、AppKit、WebKit 和 Swift Package Manager**，不依赖第三方 Swift 包。`example/` 是独立的 Windows WPF 参考项目，不参与 macOS 构建，也不与当前应用直接共享资料库格式。

## 主要功能

| 功能 | 支持内容 |
| --- | --- |
| 课程与资料 | 课程归档、复制入库或外部引用、物理文件夹、标签与备注、收藏、批量管理、ZIP 导出；中文数字章节自然排序 |
| Finder 同步 | 自动识别库内文件和文件夹改名、移动及跨课程归属；移出资料库后保留记录并标记位置丢失 |
| 作业目录 | 每门课程独立的普通磁盘目录，也可挂载资料库外已有文件夹 |
| 计划与 DDL | 月／周／日视图、执行时间与截止时间、重复计划、单次调整、完成状态及计划撤销 |
| AI 助手 | 在应用内连接 OpenAI 兼容模型，查询和编辑计划、课程与资料信息；写入前确认 |
| 外部 MCP | 25 个共享工具，支持 stdio / Streamable HTTP、版本冲突检查及远程客户端 SSH 转发 |
| 教务与教学网站 | 南京大学本科课表导入、调课与停课；Moodle 新增资料、作业与 DDL 的检查和选择性同步 |
| 备份与恢复 | 完整备份、资料库复制迁移；恢复进程中断后自动回滚或完成提交，保留 History 副本 |
| 外观与导航 | 全局搜索、后退／前进、可配置顶栏、七页设置、明暗主题和可选过渡动画 |

## 本机启动

需要 **macOS 14+** 和提供 **Swift 6+** 的 Xcode 或 Command Line Tools。Node.js 为课表解析器测试的可选依赖。

在仓库根目录执行：

```sh
./scripts/build-macos.sh
./scripts/run-macos.sh
```

输出为 `build/Teachshelf.app`。也可双击 `Start.command`；启动脚本仅在应用包不存在时构建，修改源码后应先重新运行构建脚本。脚本不会自动替换 `/Applications/课屿.app`。

构建包含应用、MCP stdio 桥接、图标和网页解析资源，并完成 ad hoc 签名与校验。此流程用于本机运行，正式分发仍需 Developer ID 签名、公证和分发验证。构建、隔离运行及安装核对步骤见 [开发指南](docs/development.md)。

## 开发与验证

```sh
./scripts/test-macos.sh
./scripts/test-macos.sh --filter BackupRestoreRecoveryTests
```

测试脚本运行 Swift 回归；检测到 Node.js 时还会运行本科课表解析测试。原生窗口、WebKit 和文件事件相关测试需要 macOS 系统服务。故障注入仅使用独立临时资料库。

## 数据与恢复

默认资料库位于 `~/Library/Application Support/Teachshelf`。课程资料默认存于 `files/<课程名> [<课程UUID>]/资料/<文件夹层级>/`，作业存于同一课程的 `作业/`。文件夹及子文件夹都是物理目录；索引保存资料身份、课程关联、标签、计划等信息。

- 支持读取并迁移旧格式 1–8；当前写入格式 9。迁移后应继续使用支持格式 9 的应用。
- Finder 中移动或改名已入库内容会自动对账；新增文件仍需主动导入。移出资料库的资料保留记录，之后可重新定位。
- `.teachshelfbackup` 包含索引、库内资料、作业和 History。**外部引用与挂载目录只备份路径，不备份外部内容。** AI 密钥、MCP 令牌及网站登录会话也不在资料库备份中。
- 恢复备份采用持久化事务，以新索引原子替换为提交点：提交前中断还原旧状态，提交后完成新状态与清理；恢复先于 Finder 对账。
- 成功恢复保留 `History/Restore-<UUID>/`。遇到损坏日志、缺失关键文件或无法确认的目录状态，会停止并保留现场，不能删除日志强行继续。

目录示例见 [使用指南](docs/usage.md#课程文件与作业目录)，恢复阶段、失败处理和验证边界见 [备份恢复说明](docs/backup-restore.md)。

## 当前边界与后续待办

- AI 与 MCP 操作元数据和物理结构，当前不读取 PDF／Word 正文、不提供任意 Shell 或文件读写。
- 教学网站采用仅新增策略，尚不检测教师在原址替换同名文件的内容；支持范围限于已实现的 Moodle 文件夹、资源和作业类型。
- 课表导入仅支持南京大学本科系统；学校页面变更、登录失效仍可能需要更新解析器或手动登录。
- 恢复已验证真实进程终止及重复恢复，未模拟整机断电、硬件故障或网络文件系统异常。

后续优先事项：**大资料库性能、学校网站内容更新检测、正式分发**。具体范围见 [开发指南中的后续待办](docs/development.md#后续待办)。
